# Events

这里记录与 C-Star AI Hub 相关、适合公开归档的 Builder Events。它不是活动宣传墙；一场活动的长期价值，取决于它是否留下了参与者之外的人也能理解和复用的材料。

## 一场 Event 应尽量留下什么

- **Context**：为什么讨论这个问题；
- **Topic**：活动实际覆盖了什么；
- **Public Notes**：经过整理、适合公开的要点；
- **Slides**：讲者同意公开的演示材料；
- **Reading List**：原始来源和延伸阅读；
- **Follow-up Resources**：后续 Tutorial、Research Note、代码或其他公共成果；
- **Recording / Photos**：仅在获得必要授权、确认不泄露个人信息时公开。

活动人数、合作关系和参与者反馈只有在能够核实并适合公开时才记录。不根据海报、照片或转述自行推断。
